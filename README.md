# Sudoku Game (Python)

This is a simple Sudoku game made using Python as a minor college project.

## Features
- Generates a new Sudoku puzzle every time.
- 9x9 Sudoku grid.
- Click on an empty cell and enter a number using your keyboard.
- Correct answers appear in green.
- Wrong answers appear in red.
- New Game button to generate another puzzle.

## Requirements
- Python 3.x
- Tkinter (usually comes with Python)

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python sudoku.py
```

## Technologies Used
- Python

- Random module
